Porsche Sales Intelligence Dashboard

Dashboard interativo para análise de vendas de veículos Porsche, desenvolvido como projeto de portfólio na área de Análise de Dados e Business Intelligence.

Acesse o projeto

Visualizar Dashboard Online

Sobre o projeto

O objetivo deste projeto é transformar dados de vendas em informações visuais que facilitem a compreensão do desempenho comercial e apoiem a tomada de decisões.

A dashboard apresenta indicadores de vendas, filtros interativos e visualizações para explorar diferentes dimensões dos dados.

Principais funcionalidades

Visão geral: indicadores e resumo do desempenho das vendas.

Análise por modelo: comparação dos modelos Porsche vendidos.

Vendas por estado: análise geográfica do volume de vendas.

Evolução temporal: acompanhamento das vendas ao longo do tempo, com diferentes granularidades.

Formas de pagamento: exploração da distribuição das vendas por método de pagamento.

Filtros interativos: seleção por modelo, ano do modelo, cidade e forma de pagamento.

Insights comerciais: visualizações que ajudam a identificar padrões e oportunidades de análise.

Tecnologias utilizadas

HTML: estrutura da dashboard.

CSS: layout, identidade visual e estilização.

JavaScript: interatividade, filtros, cálculos e visualizações.

Excel: base de dados utilizada no projeto.

GitHub Pages: publicação e hospedagem da dashboard.

Base de dados

O projeto utiliza uma base de dados de vendas preparada para análise, com informações sobre modelos, datas, preços, quilometragem, localização, formas de pagamento e status de entrega.

Os dados devem ser interpretados de acordo com as características e limitações da base utilizada.

Objetivo de aprendizado

Este projeto demonstra a aplicação prática de conceitos de análise exploratória, organização de informações, visualização de dados e desenvolvimento de dashboards interativos.

Área de interesse: Análise de Dados | Business Intelligence | Visualização de Dados
